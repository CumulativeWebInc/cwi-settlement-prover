Honest limits

  
    
    
  • Public RPCs only. We query free public endpoints (no API keys). If they're rate-limited, we say so — we never fabricate data.
    • 
    
  • Native transfers in v1. Token (ERC-20) and contract-call amounts are not decoded; contract interactions return UNSUPPORTED, not a guess.
    • 
    
  • Confirmations are probabilistic. 12+ is the common exchange heuristic, not a guarantee — reorg risk never reaches zero, and Base finality also depends on L1 batching.
    • 
    
  • We verify the chain, not the deal. A SETTLED verdict proves value moved on-chain as claimed — not that the goods were delivered or the invoice was legitimate.
    • 
    
  • Not financial advice. This is a verification tool, not investment guidance.
